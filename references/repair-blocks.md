# 返修提示词模块

这些模块用于用户反馈后的局部修正。默认原则是：只改用户点名的问题，锁定已经通过的主体、背景和构图。

## 锁定已通过对象

用户已经认可的主体、姿态、头部比例、表情、颜色、背景或整体构图必须保持不变。后续返修只影响用户明确点名的编号和问题。

如果用户说“第 X 保持不变”，则第 X 个主体不能重绘、不能换姿势、不能缩放、不能改变颜色、不能改变接地点。

## 只修改指定主体

只修改第 X 个主体，其他主体和背景保持不变。已经通过审核的主体不要重绘、不要换姿势、不要缩放、不要改变头部比例、不要改变颜色、不要改变接地点。

本轮只修正用户指出的问题。不要顺手优化其他区域。

## 接地/贴合修复

请只修复第 X 个主体与真实场景的贴合问题。保持该主体已通过的头部、主体特征、颜色和姿态不变，调整下半部分、边缘或接触点，使它明确落在原图对应的地面、桌面、椅面、台阶、墙面或手持位置上。

不要让主体看起来悬浮。不要改变其他主体和背景。

## 脚底接地修复

请只修复第 X 个人物的脚底接地问题。保持头部、上半身、服装、表情、姿势和其他人物不变。将第 X 个人物的腿部和鞋底调整到正确地面位置，让鞋底明确接触地面线或支撑面。

不要让人物看起来漂浮，也不要改变群体相对身高。

## 相对大小修正

请根据目标图或用户最新要求调整主体之间的相对大小。风格化可以改变绝对比例，但不能颠倒原图中的高矮、远近、坐站、主次和遮挡关系。

只调整需要修正的主体尺寸、身体长度、接地点或贴合位置，保持已通过主体不变。

## 相对高度修正

请调整人物相对高度，使第 X 个人物比第 Y 个人物略高，同时第 Z 个人物与第 Y 个人物一样高。只通过身体长度、腿部、鞋底和站位微调实现，不要改变已认可的头部比例和脸部造型。保持其他人物不变。

## 头部不变身体调整

请保持第 X 个主体的头部大小、脸、发型或顶部轮廓和头部位置不变，只调整头部以下的身体、腿部、衣摆或支撑部分。调整后仍要符合所选风格，并保持接地或贴合关系。

不要改变已认可的头部比例、表情和关键特征。

## 头部不变身体拉长

请保持第 X 个人物的头部大小、脸、发型和头部位置不变，只把身体适当拉长。拉长范围应集中在脖子以下的躯干、腿部或衣摆，不要把头缩小，不要改变已认可的表情和发型。

脚底仍要接地，并且相对身高要符合用户指定关系。

## 原主体残留修复

请只修复原图主体残留问题。重点检查脸、手、鞋、衣服边缘、头发边缘、身体轮廓旁的旧图痕迹。用背景修补或新主体遮盖清理残留，但不要改变已通过的新主体造型和背景大结构。

## 最终质检

请在输出前自检：主体数量正确；每个主体的位置和顺序正确；遮挡关系正确；接地或贴合正确；相对大小符合目标图或用户最新要求；原始主体没有残留；背景没有新增无关内容；没有文字、Logo 或清晰符号被错误添加到主体上；风格严格符合所选 Style 文件。
