# Style 2 参考图使用说明

`reference.png` 只作为视觉风格锚点，用来参考画法、线条、整体比例感觉、简化方式、石板灰蓝粗马克笔轮廓、Q 版头身比例、实心黑发块、扁平色块和少量纸纹扫描感。

不要继承参考图里的人物身份、运动员属性、球衣、号码、队徽、Logo、签名、足球、道具、姿态、构图、文字、表情情绪或任何标识。目标图和用户请求始终决定画谁、画什么、主体关系、服装类型、空间位置、画面内容和脸部情绪。

参考图中的怒眉、皱眉、竞技神情、红色号码、球衣徽章、签名和足球都是参考图内容，不属于 Style 2 的通用风格元素。除非用户明确要求，生成时不得把这些元素迁移到目标图。

使用 Style 2 时，应同时使用：

- `style.md`：文字风格强约束。
- `reference.png`：视觉风格参考。
- 本说明：参考图取用边界。
